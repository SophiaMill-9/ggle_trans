Browser sync (avoids 429)

Google rate-limits Cloudflare Worker IPs. This runs the Google fetch from your browser (same as DevTools), then sends results to Supabase.

  1. Keep this dashboard tab open.
  2. Click Open Google tab (must use this button — links back here).
  3. On the Google tab: DevTools → Console → paste script → Enter.
  4. Results save automatically on this tab.

Paste cURL from DevTools

Open adstransparency.google.com → DevTools → Network → SearchCreatives → right-click → Copy as cURL. Token and Cookie are parsed automatically.
